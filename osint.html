EXIF Data Info

Information about image metadata extraction

EXIF data contains metadata like camera settings, GPS coordinates, timestamps, and software used. Client-side extraction requires JavaScript libraries like exif-js. 

Common EXIF Fields:
• Camera Make/Model
• Date/Time Original
• GPS Latitude/Longitude
• Software Used
• Image Dimensions
• ISO Speed
• Focal Length
• Exposure Time

Recommended Tools:
• exiftool (command line)
• Jeffrey's Image Metadata Viewer
• Exif Pilot (Windows)
• Photo Investigator (macOS)

Document Metadata

Information about document metadata analysis

PDF, Office docs, and other files contain metadata about creation, modification, and authors. 

Common Metadata Fields:
• Author/Creator
• Creation Date

• Comments/Keywords
• Edit History
• Template Used

Analysis Tools:
