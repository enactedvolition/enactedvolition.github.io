Mottled

Mechanistic interpretability · latent dynamics

Mottled records a transformer's residual stream after every block and plays it back in the browser, so you can see where in the layer stack two similar prompts split apart and where a model's state stops changing.

Logit-lens readouts, attention patterns, SAE features (each checked for fit to the model) and an exact attention/MLP decomposition all attach to one data type, StateTrajectory.

Sample scenes cover GPT-2, DistilGPT-2 and Qwen2.5-1.5B-Instruct; the portability study and the blast samples used Qwen2.5-0.5B-Instruct. Limits: the 2D projection is lossy, and every scene reports how much it kept.

Meth × neurodivergent reward architecture

Computational neuropharmacology

ADHD stimulants and methamphetamine act on the same dopamine machinery, with opposite clinical outcomes. This simulation links six layers to ask why: DAT reverse transport and VMAT2 packing, temperature-dependent oxidative toxicity, LC–NE gain control, trial-level reinforcement learning, sleep and circadian modulation, and setpoint drift over 365 days.

In the model, temperature is a bifurcation parameter for neurotoxicity, and the same exposure gives different trajectories for neurotypical, ADHD-C and ADHD-I parameter sets. It is a model, and it is not medical guidance.

The RL layer now uses ANCCR (Jeong et al. 2022) with IRI-scaling per Burke et al. 2026. The learning rate used to be a fitted constant; it now comes from the interval between rewards, so total conditioning time no longer depends on trial frequency.

EVT-1

Agent-native trust infrastructure

A draft protocol for letting shopping agents check product claims themselves. Each product gets a deterministic ID (a canonical URN), and claims about it are signed with Ed25519, so an agent can verify them without trusting the store that showed them.

The server stores and serves signatures. Agents verify locally, so the server is not a trust root. An MCP server exposes the workflow as agent tools. Status: spec and reference server. Outside users: none visible on GitHub (0 stars, 0 forks, no issues from others as of 2026-10-09).

04

How I work

Four rules I apply to both the interpretability code and the pharmacology code, each with an example.

01

Show what the picture loses

A 2D view of a high-dimensional state is lossy, so each view reports its own fidelity. Example: the catalogue analysis flags three features that turned out to be track length.

02

One interchange type

Capture code and renderers only meet at StateTrajectory. Example: GPT-2 and Qwen captures load in the same viewer.

03

Derive, don't fit

Prefer a mechanism to a tuned constant. Example: the RL learning rate now comes from the reward interval (ANCCR).

04

It must run offline

Synthetic backends let the pipeline run and be tested with no model download, API key or network.
