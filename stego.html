Image Steganography // LSB Encoding // AES-256-GCM

OPERATIONAL PROTOCOL: This tool uses Least Significant Bit (LSB) encoding to hide encrypted messages within PNG images. Messages are encrypted using AES-256-GCM (Web Crypto API) before embedding. The visual appearance of the image remains virtually unchanged. Privacy guarantee: All operations run entirely client-side in your browser. No data is transmitted to any server.

Technical Details: Encryption uses PBKDF2 (100,000 iterations) for key derivation from your password. Each encryption operation generates a unique random salt and IV. Limitations: Maximum message size depends on image dimensions. Larger images can hide longer messages.
